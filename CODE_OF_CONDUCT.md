# Code Of Conduct

This project aims to be a respectful, research-friendly, and engineering-serious collaboration space.

## Expected Behavior

- Be respectful and constructive.
- Critique ideas, code, claims, and designs without attacking people.
- Prefer clarity and evidence over posturing.
- Keep security discussions responsible and bounded.

## Unacceptable Behavior

- harassment or personal attacks
- deliberately unsafe sample sharing
- publication dishonesty or knowingly misleading claims
- disclosure of secrets or private vulnerability details in public threads

## Scope

This applies to repository issues, pull requests, code review, discussions, and other project collaboration spaces.

## Enforcement

Project maintainers may remove content or limit participation when behavior undermines safety, respect, or responsible research practice.
